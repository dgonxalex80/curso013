Solución del caso 1: análisis descriptivo de beer2

dgonzalez

Objetivo

Describir las características comerciales, nutricionales, geográficas y de valoración contenidas en beer2.csv, mediante tablas de frecuencias, indicadores estadísticos y gráficos apropiados para cada tipo de variable.

Revisión de la base

revision <- data.frame(
  indicador = c("Registros", "Variables", "Valores faltantes", "Cervezas diferentes", "Marcas diferentes"),
  resultado = c(
    nrow(beer2),
    ncol(beer2),

Valoraciones ordinales

Las puntuaciones de calificación, aroma, apariencia, paladar y sabor son variables ordinales. Se resumen mediante sus distribuciones y la mediana; la media se incluye como referencia comparativa por tratarse de puntuaciones numéricas con intervalos uniformes.

variables_valoracion <- c("calificacion", "aroma", "apariencia", "paladar", "sabor")

resumen_valoraciones <- lapply(variables_valoracion, function(v) {
  x <- beer2[[v]]
  data.frame(
    variable = v,
    mínimo = min(x),
    mediana = median(x),
    moda = as.numeric(moda(x)),
    media = mean(x),
    máximo = max(x)
  )
}) |>
  bind_rows() |>
  mutate(across(where(is.numeric), ~ round(.x, 2)))

Variables cuantitativas

variables_cuantitativas <- c("precio", "alcohol", "carbohidratos", "calorias")

resumen_cuantitativas <- lapply(variables_cuantitativas, function(v) {
  x <- beer2[[v]]
  data.frame(
    variable = v,
    mínimo = min(x),
    q1 = quantile(x, 0.25),
    mediana = median(x),
    media = mean(x),
    q3 = quantile(x, 0.75),
    máximo = max(x),
    desviación = sd(x),
    cv_porcentaje = 100 * sd(x) / mean(x)
  )
}) |>
  bind_rows() |>
  mutate(across(where(is.numeric), ~ round(.x, 2)))

Relación entre alcohol y calorías

cor_alcohol_calorias <- cor(beer2$alcohol, beer2$calorias)
data.frame(
  variables = "Alcohol y calorías",
  correlación = round(cor_alcohol_calorias, 3)
) |>
  kable()
variables correlación
Alcohol y calorías 0.996

La correlación entre alcohol y calorías es 0.996. La asociación es positiva porque el alcohol aporta energía al contenido calórico total; además, las calorías fueron construidas usando el alcohol y los carbohidratos.

Conclusiones

  1. La base contiene 1.586.614 reseñas completas y permite analizar tanto características del producto como valoraciones de los consumidores.
  2. El tipo de cerveza predominante es cerveza normal y helada y el origen predominante es importada.
  3. La calificación general típica, medida mediante la mediana, es 4 puntos.
  4. El precio y varias características nutricionales fueron simulados; por ello, sus resultados describen esta base académica y no deben interpretarse como precios o composiciones oficiales del mercado.
  5. Los resultados son descriptivos. Para hacer inferencias causales o generalizar a todos los consumidores sería necesario conocer el diseño de muestreo y controlar la repetición de reseñas por cerveza y por usuario.
